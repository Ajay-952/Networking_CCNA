What is VLSM?
- VLSM(Variable Length Subnet Masking) is a subnetting technique that allow us to divide a network into subnets of different sizes.
- In traditional subnetting, all subnets usually have same subnet mask and the same number of host addresses. 
- With VLSM, each subnet can have a different subnets mask depending on how many hosts that subnet needs.
- VLSM allows us to use differnt-sized subnets within the same network, which reduces IP address wastage.

Example:
Consider a company with different departments:

```text
IT Department       → 100 hosts
HR Department       → 30 hosts
Management          → 10 hosts
Point-to-Point Link → 2 hosts
```
Suppose we have:

```text 
192.168.1.0/24
```
If we use the ssame subnet size for every department, we might choose "/25."
A "/25" provides:

```text
2⁷ - 2 = 126 usable hosts
```
Every department would receive 126 usable addresses:

```text
IT          → 126 addresses
HR          → 126 addresses
Management  → 126 addresses
Link        → 126 addresses
```
This would waste a huge number of IP addresses.

#### VLSM solves this.
We can assign different subnet sizes:
```text
IT          → /25 → 126 usable hosts
HR          → /27 → 30 usable hosts
Management  → /28 → 14 usable hosts
Link        → /30 → 2 usable hosts
```
Now each subnet is sized according to its actual requirement.

```text
Normal subnetting / FLSM
        ↓
Divide network into equal-sized subnets

VLSM
        ↓
Divide network into different-sized subnets
        ↓
Give each subnet only the addresses it needs
        ↓
Reduce IP address wastage
```
##### VLSM is essentially a smarter form of subnetting where different subnet masks are used within the same network to allocate IP addresses efficiently.
